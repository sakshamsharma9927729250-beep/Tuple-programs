# Tuple Programs & Dictionary Programs

This repository contains simple Python examples demonstrating how to use tuples and dictionaries.

## 📚 Tuple Programs

- [main.py](main.py): includes beginner-friendly programs showing:
  - tuple creation and basic operations
  - indexing and slicing
  - nested tuples
  - tuple unpacking
  - tuple methods like `count()` and `index()`
  - tuple immutability
  - converting between tuples and lists

- [main2.py](main2.py): contains additional tuple programs showing:
  - membership checks using `in` and `not in`
  - comparing tuples
  - repeating tuples with `*`
  - combining tuples using concatenation (`+`)
  - iterating through combined tuple values

## 🔑 Dictionary Programs

- [dict.py](dict.py): contains 5 beginner-friendly dictionary programs:

  **Program 1: Creating and Accessing Dictionary**
  - Create a dictionary with key-value pairs
  - Access elements using dictionary keys
  - Use the `get()` method for safe access

  **Program 2: Adding and Updating Dictionary**
  - Add new key-value pairs to a dictionary
  - Update existing dictionary values
  - Use the `update()` method to add multiple items at once

  **Program 3: Deleting Items from Dictionary**
  - Delete items using `del` keyword
  - Remove and return items using `pop()` method
  - Remove the last inserted item using `popitem()` method
  - Clear all items from a dictionary using `clear()` method

  **Program 4: Iterating Through Dictionary**
  - Iterate through dictionary keys
  - Iterate through dictionary values
  - Iterate through key-value pairs using `items()` method
  - Use enumerate() to iterate with index

  **Program 5: Dictionary Methods and Operations**
  - Check if a key exists in dictionary
  - Get all keys, values, and items using `keys()`, `values()`, `items()`
  - Get dictionary size using `len()`
  - Copy a dictionary using `copy()` method
  - Create dictionary from list of tuples
  - Merge dictionaries using unpacking operator `**`
  - Sort dictionary by keys and values

## 🚀 Running the Scripts

Run the tuple programs:
```bash
python3 main.py
python3 main2.py
```

Run the dictionary programs:
```bash
python3 dict.py
```

You will see different examples printed to the console with explanatory output for each program.
